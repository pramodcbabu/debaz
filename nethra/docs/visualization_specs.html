Nethra Command Center: Visualization Specs

1. Dashboard User Flow

The UI is designed for high-stakes decision-making under pressure. It follows a "Macro-to-Micro" discovery pattern.

graph LR A[State/District Map View] --> B[Booth Volatility Heatmap] B --> C{Select Volatile Booth} C --> D[Issue & Sentiment Deep-Dive] D --> E[Simulated Anomaly Check] E --> F[Audience Size: 240 Swing Voters] F --> G[Intervention: Dispatch AI Ad Campaign] G --> H[Real-time ROI Monitoring]

3. Visual Design Standards

  • Theme: Dark Mode primary (reduces eye strain for campaign managers during late-night war-room sessions).
  • Geospatial: Uses MapBox GL JS for fluid zooming into booth-level boundaries.
  • Sentiment Indicators: Green (+1.0) for supporters, Red (-1.0) for angry opponents, and Yellow (0) for identified swing voters.
  • Gradients: Heatmaps use a Purple-to-Orange gradient to denote "Volatility", distinguishing it from simple "Support" maps.

4. Intervention Verification UI

After a campaign is dispatched, the dashboard switches to an "A/B Tracker" view, showing real-time engagement lifts in the targeted Treatment booths versus the Control booths.
