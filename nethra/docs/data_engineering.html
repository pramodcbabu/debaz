3. Data Mirroring & Simulation

Public Data Mirroring

We utilize the /data/public/ directory to store mirrored datasets from the Election Commission of India (ECI). These are parsed from raw PDFs into structured JSON/Parquet files using our custom scrapers.

Private Data Simulation

Since actual voter sentiment data is proprietary, Nethra uses a Synthetic Voter Engine to generate simulated private data for testing.

  • Stochastic Distribution: We use Gaussian distributions centered around real historical results to generate believable voter clusters.
  • Issue Propagation: Grievances are simulated using a "Viral Issue Model"—if one voter in a booth is assigned a "Water Crisis" issue, the probability of neighbors having the same issue increases by 30%.
  • Cadre Noise: 15% of cadre reports are intentionally corrupted with "Over-Optimism Bias" to test the Anomaly Detection engine.
