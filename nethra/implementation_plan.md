# Full Nethra Prototype Implementation

## Goal Description

Implement the complete Nethra prototype for the UP 2027 Assembly elections, including data crawling, MRP engine, Streamlit UI, LaTeX quality checks, and a 5‑perspective review (Political Leadership, ML/Data Engineering, Behavioral Psychology, Ethics & Data Privacy, Product Management). Parallel subagents will be used to accelerate data acquisition, LaTeX linting, and perspective reviews.

## User Review Required

> [!IMPORTANT]
> No breaking changes are introduced beyond the planned components. Review is needed only for any UI design preferences (color scheme, branding) and confirmation of the target public data sources for the 2027 election.

## Open Questions

> [!WARNING]
> - **UI Styling:** Do you prefer a dark‑mode glassmorphism theme or a light minimalist design for the Streamlit app?
> - **Data Sources:** Apart from the Election Commission of India archives, are there any additional public datasets (e.g., GIS shapefiles) you want the crawler to ingest?
> - **Performance Constraints:** Should the prototype limit the number of booths processed to a subset for quick demo, or run on the full dataset?

## Proposed Changes

---
### Data Acquisition & Crawling

- **[NEW]** `src/data_crawler.py` – Scrapes election result PDFs/CSV for UP 2027, extracts Form 20 tables, stores raw files in `data/raw/`.
- **[NEW]** `src/utils/download_helper.py` – Helper functions for robust HTTP downloads with retry logic.
- **[MODIFY]** `implementation_plan.md` – Added Section 0 describing crawling requirements.

---
### Mock Data Generation

- **[MODIFY]** `src/generate_mock_data.py` – Completed script to synthesize demographic strata and booth‑level features, output to `data/mock/`.

---
### MRP Engine

- **[NEW]** `src/mrp_engine.py` – Core MRP implementation:
  - Multilevel regression with demographic covariates.
  - Booth‑level random intercepts using HV and HM predictors.
  - Bayesian shrinkage via PyMC.
- **[NEW]** `src/model_config.py` – Configuration dataclasses for model hyper‑parameters.

---
### Streamlit UI

- **[NEW]** `app.py` – Streamlit entry point:
  - Sidebar for selecting constituency, election year, and model parameters.
  - Main view shows booth‑level swing heatmap (Plotly), demographic breakdown tables, and downloadable CSV.
  - Integrated with `mrp_engine` and mock data.
- **[NEW]** `assets/style.css` – Premium glassmorphism dark‑mode stylesheet (custom fonts, smooth gradients, micro‑animations).

---
### Documentation & LaTeX Quality Assurance

- **[NEW]** `src/latex_linter.py` – Scans markdown files for LaTeX syntax errors, auto‑fixes common issues (underscore handling, block math formatting).
- **[MODIFY]** All `docs/*.md` files (e.g., `up_form_20_analysis.md`, `mathematical_model.md`) to conform to the LaTeX Quality Gate.

---
### Perspective Review Subagents

- **[NEW]** `agents/perspective_reviewer/` – Subagent that evaluates the prototype from each of the five mandated perspectives and writes a `docs/perspective_review.md` report.
- **[NEW]** `agents/latex_linter/` – Subagent that runs `latex_linter.py` on the documentation repository.
- **[NEW]** `agents/data_agent/` – Subagent that runs `data_crawler.py` and stores results.

---
### CI / Verification

- **[NEW]** `tests/test_mrp_engine.py` – Unit tests for regression coefficients and poststratification logic.
- **[NEW]** `tests/test_app.py` – Simple Selenium‑based smoke test to ensure Streamlit launches without errors.

## Verification Plan

- Run `pytest -q tests/` after implementation.
- Execute `python src/latex_linter.py` and ensure zero lint warnings.

### Manual Verification
- Launch `streamlit run app.py` and confirm UI renders with premium styling, interactive heatmap loads, and CSV download works.
- Review `docs/perspective_review.md` generated by the perspective reviewer subagent.
- Validate that `data_crawler` has populated `data/raw/` with at least one sample Form 20 file for UP 2027.

### Acceptance Criteria
- All unit tests pass.
- No LaTeX rendering errors in GitHub preview.
- Streamlit UI displays with the chosen design theme.
- Perspective review report covers each of the five mandated viewpoints.
- Repository builds and runs locally with `npm run dev` not applicable (pure Python).
