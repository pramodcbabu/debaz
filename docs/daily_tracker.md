# Daily Operations Tracker: Process & Pipeline

To optimally manage daily "Liaising" inquiries (e.g., solar plant installation, roads in Delhi, real estate advances) without derailing the main strategic timeline, implement a lightweight **"Daily Input Triage"** system.

## Recommended Process

1. **The Daily 15-Minute Triage:** Do not execute on new liaising inquiries immediately. Instead, spend 15 minutes at the end of each day recording any new inbound opportunities into the tracker below.
2. **Weekly Prioritization:** During the "Byso Global" block on Monday, review the backlog. Select **only one** high-value connection/deal to pursue for that week to ensure you remain within the 2 hours/day constraint.
3. **Status Updates:** Move items through the pipeline (New ➡️ Active ➡️ Closed/Lost).

## Guidelines for Optimal Recording

*   **GitHub Issues (Alternative to this file):** If the backlog grows large, consider using GitHub Issues on your `debaz` repository. You can create an issue for "Solar Plant Installation", label it as "Liaising", and use the comments to track communication.
*   **Qualify Fast:** Before spending time connecting parties, ensure both parties have provided proof of funds or legitimate intent. If an opportunity sits in "New" for more than 2 weeks, discard it to keep focus.
